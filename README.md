# Котофей — бюджет рекламы по погоде

Служебный проект без сайта. Каждое утро (02:00 UTC, около 07:00 по Астане) Vercel вызывает
`/api/weather-budget`. Скрипт берёт прогноз Open-Meteo на сегодня и ставит группам объявлений Meta
обычный или повышенный дневной бюджет.

## Где что менять

- `lib/weather-budget.ts` — города, ID групп объявлений и кампаний, обычные бюджеты в долларах, процент повышения и пороги осадков.
- `vercel.json` — расписание.

## Переменные окружения в Vercel

| Имя | Значение |
|---|---|
| `META_ACCESS_TOKEN` | токен системного пользователя Meta с правом `ads_management` |
| `CRON_SECRET` | длинная случайная строка, пароль на запуск |
| `WEATHER_DRY_RUN` | `true` — только отчёт в журнал; `false` — менять бюджеты |

Необязательные: `META_API_VERSION` (по умолчанию `v23.0`), `META_CURRENCY_OFFSET` (по умолчанию `100`).

## Как остановить

Поставьте `WEATHER_DRY_RUN=true` и пересоберите проект или отзовите токен в Business Manager.
